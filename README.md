# Four Card Feature Section

A responsive feature card layout built using HTML, CSS, and Flexbox. This project mimics a professional UI component often used in landing pages, showcasing 4 key features in a visually balanced way.

## 💻 Demo

(https://github.com/user-attachments/assets/c4a1f658-76eb-4e77-b317-0c21e54507fa)




## 🚀 Features

- Clean and modern card design
- Fully responsive (wraps at 750px)
- Center-aligned card group with colored borders
- Uses Google Fonts (Poppins)
- Semantic and accessible HTML


## 🔧 Technologies Used

- HTML5
- CSS3 (Flexbox)
- Google Fonts (Poppins)
